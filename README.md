# Khushbu & Harsh Wedding Invitation

## Music
The uploaded MP3 is stored at `assets/wedding-song.mp3`.
Music starts when a guest first touches/scratches the scratch-to-reveal wedding-date card. This user gesture is compatible with mobile browser audio restrictions. The music button can also play/pause the track.

## Publish on GitHub Pages
1. Create a public GitHub repository, e.g. `khushbu-harsh-wedding`.
2. Upload `index.html`, `README.md`, and the entire `assets` folder to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** in the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then click **Save**.
7. Wait for deployment. GitHub Pages will display the public website URL in the Pages settings.

Do not rename or move `assets/wedding-song.mp3` unless you also update its path in `index.html`.
